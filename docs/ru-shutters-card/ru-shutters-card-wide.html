Home Assistant — shutter card, wide layout
Companion to Shutter Cards (option 2a). Same palette and components — when the card is given room, the room list moves left and the selected room's draggable windows sit beside it as a pane instead of a popup. Tapping a room selects it (outlined in blue); the first room is selected until then.
1Wide layout — room list + detail pane
Driven by a CSS container query on the card's own width: @container (min-width: 720px) splits list | pane; from 1000px the room grid goes to 3 columns. Below 720px the card is the phone layout and the drilldown stays a popup.
